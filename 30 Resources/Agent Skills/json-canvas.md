# 🗺️ Obsidian Canvas

Obsidian Canvas (`.canvas` kengaytmali fayllar) yordamida g'oyalar, fayllar va havolalarni vizual xaritalar shaklida guruhlash, bir-biri bilan bog'lash mumkin.

## 🧱 Canvas fayllarining tuzilishi (JSON formatida):
Canvas fayllari orqa fonda JSON ma'lumotlaridan iborat bo'lib, ular quyidagi qismlarni o'z ichiga oladi:
* `nodes`: Vizual bloklar (matnlar, rasmlar, boshqa qaydlar).
* `edges`: Bloklarni bir-biri bilan bog'lovchi chiziqlar va yo'nalishlar.

## 🔗 Node turlari:
1. **Text Node** — to'g'ridan-to'g'ri Canvas ichida yozilgan matnlar.
2. **File Node** — vault-dagi mavjud qaydlar yoki rasmlar.
3. **Link Node** — internetdagi havolalar (URL).
