# 🔍 Veb Qidiruv va Ma'lumot To'plash Protokoli (Web Scraping Protocol)

> *"Internetdagi cheksiz ma'lumotlar ummonidan faqat eng qimmatli, toza va aniq faktlarni ajratib olish."*

Ushbu protokol AI agentlari internetdan yangi kutubxonalar, me'moriy yechimlar va bozor tahlillarini qanday samarali to'plashini belgilaydi.

---

## 🛠️ Qidiruv Vositalari va Qo'llanilish Qoidalari

1. **Defuddle CLI**:
   - Veb-sahifalardan ortiqcha reklamalar, menyular va skriptlarni olib tashlab, toza Markdown chiqaradi.
   - Buyruq: `defuddle parse <url> --md`.
2. **Google Web Search**:
   - Yangi texnologik tendensiyalar va texnik hujjatlarni qidirish.
3. **Chrome DevTools & Network Audit**:
   - Veb-ilovalarning API tuzilishi, JSON so'rovlari va resurslarini tahlil qilish.
